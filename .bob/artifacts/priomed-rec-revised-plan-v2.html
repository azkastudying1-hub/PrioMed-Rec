Sub-Task 5 — Synthetic Label Revision (Critical)

Problem

Current has_discrepancy = np.random.choice([0,1], p=[0.40, 0.60]) — completely random, confirmed ROC-AUC ~0.50. The spec explicitly rejects this.

Revised Label Logic

LabelTrigger (derived from Synthea data)Status
NONEPre-admission and admission lists concordantACTIVE
OMISSIONMedication in pre-admission window (authored_on < encounter_start) absent from admission list — RxNorm primary keyACTIVE
DUPLICATIONSame RxNorm code ≥2 times in admission listACTIVE
DOSE_DISCREPANCYSame medication, different dose_value — ONLY if dose_value non-null in both recordsACTIVE
FREQUENCY_DISCREPANCYfrequency 100% null (DQI-005)DISABLED
ROUTE_DISCREPANCYroute 100% null (DQI-005)DISABLED

New Schema: synthetic_cases.csv

case_id, patient_id, encounter_id, mutation_type, source_medication_code, source_medication_name, random_seed, label, mutation_description, provenance
