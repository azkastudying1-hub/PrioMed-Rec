## 4. Encoding

All files use **UTF-8 with BOM** (`\xef\xbb\xbf` prefix detected). The loader [`src/data/loaders.py`](../src/data/loaders.py) uses `encoding="utf-8-sig"` to strip the BOM automatically.

Exception: `validation_report.csv` has no BOM.

---

## 5. Pre-computed Datasets

`primedrec_master.csv` and `primedrec_risk_features.csv` were generated in a prior Colab session by joining and aggregating the raw Synthea tables. They are treated as **derived inputs**, not ground-truth raw data.

- `primedrec_master.csv` contains duplicate columns from the join (`encounter_start_x/y`, `birth_date_x/y`). Canonical resolution documented in `docs/data_dictionary.md`.
- `primedrec_risk_features.csv` contains only 9 base features. The full feature matrix will be recomputed in Sub-Task 4.

---

## 6. Clinical Safety Note

All data is **entirely synthetic**. It was generated by Synthea and does not represent or contain any information about real patients. This dataset is suitable for algorithm development and testing purposes only.

---

## 7. Reproducibility

To regenerate the raw data, a Synthea run with the same seed and population configuration is required. The exact Synthea version and seed used for this dataset are not available (generated in prior project phase). The pipeline is designed to work with the current verified files as-is.
