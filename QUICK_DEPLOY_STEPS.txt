STEP 1: DEPLOY FRONTEND TO VERCEL (10 minutes)
─────────────────────────────────────────────────────────────────────────────

1. Go to: https://vercel.com/dashboard
2. Click "Add New" → "Project"
3. Click "Import Git Repository"
4. Search for: PrioMed-Rec
5. Select: azkastudying1-hub/PrioMed-Rec
6. Settings:
   - Project Name: PrioMed-Rec
   - Framework: React
   - Root Directory: web
7. Click "Deploy"
8. Wait 3-5 minutes
9. Copy your Vercel URL (like: https://priomed-rec-xyz.vercel.app)

📝 SAVE YOUR VERCEL URL FOR NEXT STEP!


STEP 2: DEPLOY BACKEND TO RAILWAY (10 minutes)
─────────────────────────────────────────────────────────────────────────────

1. Go to: https://railway.app/dashboard
2. Click "New Project"
3. Select "Deploy from GitHub repo"
4. Authorize GitHub if prompted
5. Search & select: azkastudying1-hub/PrioMed-Rec
6. Click "Variables" tab
7. Add these variables (press + to add each):

   LLM_PROVIDER = gemini
   LLM_API_KEY = your-gemini-api-key-here
   JWT_SECRET_KEY = CHANGE_ME_generate_with_python_-c_import_secrets_print_secrets_token_hex_32
   JWT_REFRESH_SECRET_KEY = CHANGE_ME_generate_with_python_-c_import_secrets_print_secrets_token_hex_32
   DATABASE_URL = sqlite:///data/priomed.db
   CORS_ALLOWED_ORIGINS = https://YOUR-VERCEL-URL.vercel.app,http://localhost:5173
   LANGFLOW_SUPERUSER = langflow-admin
   LANGFLOW_SUPERUSER_PASSWORD = CHANGE_ME_strong_password
   ENVIRONMENT = production
   DEBUG = False
   FASTAPI_HOST = 0.0.0.0
   FASTAPI_PORT = $PORT

8. Replace "YOUR-VERCEL-URL" with YOUR actual Vercel URL from Step 1!
9. Click "Deploy"
10. Wait 5-10 minutes
11. Copy your Railway URL (like: https://priomed-rec-prod-abc.railway.app)

📝 SAVE YOUR RAILWAY URL FOR NEXT STEP!


STEP 3: CONFIGURE & VERIFY (5 minutes)
─────────────────────────────────────────────────────────────────────────────

1. Open Terminal (PowerShell)
2. Navigate to project: cd d:\Hacktiv8\priomed-rec
3. Create frontend environment file:

   echo 'VITE_API_URL=https://YOUR-RAILWAY-URL.railway.app' > web\.env.production
   echo 'VITE_APP_NAME=PrioMed-Rec' >> web\.env.production

4. Replace "YOUR-RAILWAY-URL" with your actual Railway URL!
5. Commit & push:

   git add web\.env.production

   git push origin main

6. Vercel will auto-redeploy (2-3 minutes)

7. TEST EVERYTHING:
   - Frontend: Open https://YOUR-VERCEL-URL.vercel.app
   - Backend Health: Open https://YOUR-RAILWAY-URL.railway.app/health
   - Backend Docs: Open https://YOUR-RAILWAY-URL.railway.app/docs

CORS Error in frontend?

API not responding?
→ Check: https://YOUR-RAILWAY-URL.railway.app/health
→ View logs in Railway dashboard
→ Check network in browser DevTools (F12)

Build failed?
→ Check build logs in Vercel or Railway dashboard
→ Ensure all environment variables are set

Can't access frontend?
→ Make sure Vercel deployment completed
